Small tool, no fuss.

Built for the moment you're watching something or focusing on one screen, and the other is just glowing at you.

One click

Click the tray icon and every screen except the one you clicked from goes dark. Click again to wake them all.

Wakes on cursor

Move your mouse onto a sleeping screen and it turns right back on. You never need to look for a button.

Windows stay put

Real DDC/CI standby, not "PC screen only". Windows still sees the monitor, so nothing gets rearranged.

Global hotkey

Win + Alt + O does the same thing from anywhere. You can switch it off from the tray menu.

Starts with Windows

One checkbox in the tray menu. No installer, no background service, no telemetry.

Open source

About 400 lines of plain Win32 C++ under the MIT license. Read it, build it, fork it.

Get going in a minute.

No setup wizard. It's one file.

Download and run ScreenOff.exe

A monitor icon appears in the tray. If it hides behind the ^ arrow, drag it onto the taskbar.

Click it from the screen you want to keep

Every other monitor goes into standby, and the icon fills in to show screens are sleeping.

Move the cursor back to wake a screen

Or click the icon again. Right-click for options, including Start with Windows.

FAQ

Nothing happens when I click. Why?

The other monitor needs DDC/CI enabled. It's usually an option in the monitor's own on-screen menu, often under "System" or "Other". ScreenOff shows a notification when no screen could be turned off.

Will my windows move to the other screen?

No. ScreenOff sends the monitor a standby command over DDC/CI and doesn't touch the Windows display configuration, so your layout stays exactly as it was.

Does it work with three or more monitors?

Yes. Every monitor except the one under the cursor is put to sleep, and each wakes individually when the cursor reaches it.

Is it safe for my monitor?

It uses the same standard power command your monitor's own power button and Windows' display sleep use. Nothing is overclocked or reconfigured.

Windows SmartScreen warns me about the download.

That happens with new, unsigned apps. Choose "More info", then "Run anyway", or build it yourself from the source on GitHub.
